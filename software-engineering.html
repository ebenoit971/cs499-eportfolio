Software Engineering Artifact

Overview

The artifact selected for this enhancement is a full-stack web application built using Node.js, Express, MongoDB, and Angular. The application, Travlr Getaways, includes both a customer-facing website and an administrative API.

Enhancements Made

I improved the structure and organization of the application by separating concerns into middleware, routing, and database configuration. I also implemented proper error handling, CORS configuration, and improved authentication integration using Passport and JWT.

Skills Demonstrated

This artifact demonstrates backend development, RESTful API design, authentication, middleware configuration, and full-stack integration.

Security Considerations

Security improvements include JWT-based authentication, use of environment variables to protect sensitive data, input validation, and structured error handling to reduce vulnerabilities such as unauthorized access and exposed credentials.

Stakeholder and Business Impact

These enhancements improve system reliability, scalability, and usability, ensuring that both users and developers can interact with the application efficiently while reducing operational risk.

Course Outcome Alignment

This artifact aligns with program outcomes by demonstrating the ability to design scalable computing solutions, apply secure coding practices, and communicate technical decisions effectively.

Reflection

Through this process, I strengthened my understanding of backend system architecture and learned how middleware, authentication, and API communication work together in a production environment.
