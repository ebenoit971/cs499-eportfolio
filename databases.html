Database Artifact

Overview

This artifact is a MongoDB-based dashboard application used to display and interact with animal shelter data through a table and map.

Enhancements Made

I added dynamic filtering, data visualization through charts, and improved map interaction, making the dashboard more interactive and user-friendly.

Skills Demonstrated

This artifact demonstrates database management, CRUD operations, data visualization, and backend-to-frontend integration.

Security Considerations

Security considerations include controlled data access, structured queries, and limiting user interactions to predefined filters to protect data integrity.

Stakeholder and Business Impact

The system supports decision-making by allowing users to quickly filter, analyze, and visualize data in a meaningful way.

Course Outcome Alignment

This artifact demonstrates the ability to design database-driven systems and communicate data effectively using modern tools.

Reflection

Through this project, I developed a deeper understanding of how databases, user interfaces, and data visualization work together. I faced challenges with maintaining consistent data flow and testing in a virtual environment, but successfully validated functionality through partial testing and documentation.
