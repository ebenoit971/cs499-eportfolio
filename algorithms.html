Algorithms and Data Structures Artifact

Overview

This artifact is a mobile application developed to track user weight and manage personal health data using SQLite.

Enhancements Made

I improved data retrieval by implementing sorting (descending by date) and filtering using SQL queries. This enhanced performance and usability.

Skills Demonstrated

This artifact demonstrates algorithmic problem solving, data structures, database querying, and efficient data handling.

Security Considerations

Security was considered by using structured queries and limiting data access, reducing risks such as improper data exposure and improving data integrity.

Stakeholder and Business Impact

These improvements allow users to quickly access relevant data, improving decision-making and overall user experience.

Course Outcome Alignment

This artifact demonstrates the ability to design and evaluate computing solutions using algorithmic principles and data structures.

Reflection

I learned how small improvements in data handling can significantly impact performance and usability, and how to optimize applications without disrupting existing functionality.
